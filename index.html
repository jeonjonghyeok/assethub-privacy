자산관리 개인정보처리방침

시행일 2026년 11월 2일

요약

  • 자산관리는 서버가 없는 앱입니다.
  • 입력한 자산·대출·목표·가계부 정보는 사용자의 기기에만 저장됩니다.
  • 개발자를 포함한 누구에게도 전송되지 않습니다.
  • 광고·분석 도구를 사용하지 않습니다.

1. 처리하는 정보

Google 계정 정보

이메일, 이름, 계정 식별자를 Google 로그인으로 받습니다.
앱을 사용할 사용자를 구분하고 설정 화면에 표시하는 데에만 씁니다.

은행·카드 알림 내용 (사용자가 켠 경우에만)

"알림으로 자동 기록"을 켜고 Android 설정에서 알림 접근을 허용하면 작동합니다.

  • 지정된 은행·카드·간편결제 앱과 문자 앱의 알림 문구를 이 기기 안에서 읽습니다.
  • 잔액과 입출금·결제 내역(금액, 가맹점·상대방 이름, 시각)을 기록합니다.
  • 그 밖의 앱(메신저 등) 알림은 읽지 않고 즉시 버립니다.
  • 문자 앱 알림 중에서도 금융 거래가 아닌 내용은 저장하지 않습니다.
  • 언제든 앱 설정이나 Android 설정에서 끌 수 있습니다.

개발자에게 보낸 의견 (사용자가 보낸 경우에만)

설정의 "개발자에게 의견 보내기"로 보낸 아래 내용입니다.

  • 의견 종류(버그 제보·기능 요청·기타)와 내용
  • 문제 확인을 위한 앱 버전, Android 버전, 기기 모델명

계정 정보, 이메일, 자산 정보는 함께 보내지 않습니다.

사용자가 직접 입력한 정보

  • 자산 이름·종류·금액
  • 대출 잔액·금리·상환 방식·만기일
  • 목표 금액·날짜, 목표 자산 구성 비율
  • 가계부 내역과 예산
  • 이를 바탕으로 앱이 계산한 일별 순자산 기록

계좌 비밀번호, 금융기관 로그인 정보, 주민등록번호 등은 요구하지 않으며 수집하지 않습니다.

2. 저장 위치와 전송

저장 위치

모든 정보는 사용자 기기의 앱 전용 저장공간에만 저장됩니다.
자산관리에는 별도의 서버가 없습니다.

네트워크를 쓰는 경우

  • Google 로그인
  • 사용자가 직접 연결한 코인 거래소(업비트·빗썸·바이낸스)와 증권사(한국투자증권·키움증권·LS증권)의 잔액 조회
  • 시세 조회
  • 사용자가 보낸 의견 전송
  • Google 드라이브 자동 백업(사용자가 켠 경우)
  • 기능 사용 통계(설정에서 끌 수 있음)

알림에서 읽은 내용은 기기 밖으로 전송하지 않습니다.

시세 조회

주식·코인을 수량으로 입력하면 현재가를 받기 위해 종목 코드(예: 005930, BTC)만 보냅니다.
받는 곳: 업비트, 바이낸스, 네이버 증권, 환율 제공처(Frankfurter)
보유 수량·금액·계정 정보는 보내지 않습니다.

거래소·증권사 API 키

  • 사용자가 입력한 조회용 API 키는 Android 키 저장소로 암호화해 이 기기에만 보관합니다.
  • 해당 거래소·증권사에 잔액을 조회할 때만 사용합니다.
  • 개발자를 포함한 누구에게도 전송되지 않고, 기기 백업에도 포함되지 않습니다.
  • 연결을 끊거나 데이터를 모두 삭제하면 함께 지워집니다.

백업 파일

  • "백업 파일 만들기"를 누르면 이 계정의 데이터를 사용자가 정한 비밀번호로 암호화(AES-256)합니다.
  • 파일은 사용자가 고른 위치에 저장되며, 개발자에게 전송되지 않습니다.
  • 비밀번호 없이는 누구도 열 수 없습니다.
  • 거래소·증권사 API 키는 백업에 넣지 않습니다.

Google 드라이브 자동 백업 (사용자가 켠 경우에만)

  • 데이터를 암호화해 사용자 본인의 Google 드라이브 앱 전용 공간(appDataFolder)에 저장합니다.
  • 이 공간은 자산관리 앱만 읽을 수 있으며, 드라이브의 다른 파일에는 접근하지 않습니다.
  • 개발자는 이 백업에 접근할 수 없습니다. 거래소·증권사 API 키는 넣지 않습니다.

기능 사용 통계 (설정 › 사용 통계 보내기에서 끌 수 있음)

  • 앱을 개선하기 위해 Google 애널리틱스 for Firebase로 어떤 기능을 썼는지만 익명으로 보냅니다.
    예: 가계부 화면 열기, 내역 저장, 거래소 연결 성공·실패, 자산 종류(예금·주식 등)
  • 금액, 잔액, 가맹점, 메모, 계좌번호, 알림 내용, 이메일은 보내지 않습니다.
  • 광고 ID는 수집하지 않고 광고에 쓰지 않습니다.
  • 통계는 Google 애널리틱스 기본 보관 기간(2개월) 동안 보관됩니다.

앱 잠금 (사용자가 켠 경우에만)

기기의 지문·얼굴·화면 잠금으로 본인을 확인합니다.
생체 정보는 Android가 처리하며, 앱은 확인 결과만 받습니다.

의견 보내기

  • 보낸 의견은 개발자의 Google 설문지(Google Forms)로 전송되어 개발자만 볼 수 있습니다.
  • 버그 수정과 기능 개선에만 쓰며, 답장 기능은 없습니다.
  • 받은 의견은 처리 후 1년이 지나면 삭제합니다.

Android 기기 백업

사용자가 Android 기기 백업을 켜 둔 경우, Android가 앱 데이터를 사용자 본인의 Google 계정 백업 공간에 암호화해 보관할 수 있습니다.
이는 Google의 기기 백업 기능이며, 개발자는 이 데이터에 접근할 수 없습니다.

3. 제3자 제공

정보를 제3자에게 제공하거나 판매하지 않습니다.
광고 도구는 포함하지 않으며, 분석 도구는 위의 기능 사용 통계(Google 애널리틱스 for Firebase)만 사용합니다.

4. 보관 기간과 삭제 (자산관리 데이터 삭제 방법)

기기에 저장된 정보는 사용자가 삭제할 때까지 보관됩니다.

기기의 모든 데이터 삭제

앱에서 설정 → 내 데이터 모두 삭제 → 모두 삭제를 누르세요.

  • 로그인한 계정의 자산·대출·목표·가계부·알림 기록과 거래소·증권사 키가 즉시 삭제됩니다.
  • 앱을 삭제해도 기기에 저장된 모든 정보가 함께 삭제됩니다.

보낸 의견 삭제

  • 보낸 의견(의견 종류·내용·앱 버전·Android 버전·기기 모델)은 개발자의 Google 설문지에 보관되며, 받은 지 1년이 지나면 삭제합니다.
  • 그 전에 지우고 싶다면 아래 8번의 개발자 연락처로 보낸 날짜와 내용 일부를 알려 주세요. 확인 후 7일 안에 삭제합니다.
  • 의견은 계정과 연결되지 않아 다른 정보는 보관하지 않습니다.

5. 투자 정보에 관한 안내

앱이 보여주는 목표 달성률, 필요 금액, 예상 도달 시점, 목표 구성과의 차이 등은 사용자가 입력한 값으로 계산한 결과입니다.
투자 권유나 자문이 아닙니다.

6. 아동

자산관리는 만 14세 미만 아동을 대상으로 하지 않습니다.

7. 방침의 변경

이 방침이 바뀌면 이 페이지에 시행일과 함께 게시합니다.

8. 문의

Google Play 스토어의 자산관리 앱 정보에 있는 개발자 연락처로 문의해 주세요.
