자산관리 개인정보처리방침

시행일 2026년 10월 22일
요약 — 자산관리는 서버가 없는 앱입니다. 입력한 자산·대출·목표 정보는 사용자의 기기에만 저장되며, 개발자를 포함한 누구에게도 전송되지 않습니다. 광고·분석 도구를 사용하지 않습니다.

1. 처리하는 정보

  • Google 계정 정보(이메일, 이름, 계정 식별자): Google 로그인으로 받으며, 앱을 사용할 사용자를 구분하고 설정 화면에 표시하는 데에만 씁니다.
  • 은행·카드 알림 내용(사용자가 켠 경우에만): "알림으로 자동 기록"을 켜고 Android 설정에서 알림 접근을 허용하면, 지정된 은행·카드·간편결제 앱과 문자 앱의 알림 문구를 이 기기 안에서 읽어 잔액과 입출금·결제 내역(금액, 가맹점·상대방 이름, 시각)을 기록합니다. 그 밖의 앱(메신저 등) 알림은 읽지 않고 즉시 버리며, 문자 앱 알림 중에서도 금융 거래가 아닌 내용은 저장하지 않습니다. 언제든 앱 설정이나 Android 설정에서 끌 수 있습니다.
  • 개발자에게 보낸 의견(사용자가 보낸 경우에만): 설정의 "개발자에게 의견 보내기"로 보낸 의견 종류(버그 제보·기능 요청·기타)와 내용, 그리고 문제 확인을 위한 앱 버전·Android 버전·기기 모델명. 계정 정보, 이메일, 자산 정보는 함께 보내지 않습니다.
  • 사용자가 직접 입력한 정보: 자산 이름·종류·금액, 대출 잔액·금리·상환 방식·만기일, 목표 금액·날짜, 목표 자산 구성 비율, 그리고 이를 바탕으로 앱이 계산한 일별 순자산 기록.

계좌번호, 금융기관 로그인 정보, 주민등록번호 등은 요구하지 않으며 수집하지 않습니다.

2. 저장 위치와 전송

  • 모든 정보는 사용자 기기의 앱 전용 저장공간에만 저장됩니다. 자산관리에는 별도의 서버가 없습니다.
  • 네트워크는 Google 로그인, 사용자가 직접 연결한 코인 거래소(업비트·빗썸·바이낸스)의 잔액 조회, 시세 조회, 그리고 사용자가 보낸 의견 전송에만 사용됩니다. 알림에서 읽은 내용은 기기 밖으로 전송하지 않습니다.
  • 의견 보내기: 사용자가 의견을 보내면 위 내용이 개발자의 Google 설문지(Google Forms)로 전송되어 개발자만 볼 수 있습니다. 버그 수정과 기능 개선에만 쓰고, 답장 기능은 없습니다. 받은 의견은 처리 후 1년이 지나면 삭제합니다.
  • 시세 조회: 주식·코인을 수량으로 입력하면 현재가를 받기 위해 종목 코드(예: 005930, BTC)만 업비트·바이낸스·네이버 증권과 환율 제공처(Frankfurter)에 보냅니다. 보유 수량·금액·계정 정보는 보내지 않습니다.
  • 거래소 API 키: 사용자가 입력한 조회용 API 키는 Android 키 저장소로 암호화해 이 기기에만 보관하며, 해당 거래소에 잔액을 조회할 때만 사용합니다. 개발자를 포함한 누구에게도 전송되지 않고, 기기 백업에도 포함되지 않습니다. 연결을 끊거나 데이터를 모두 삭제하면 함께 지워집니다.
  • 사용자가 Android 기기 백업을 켜 둔 경우, Android 운영체제가 앱 데이터를 사용자 본인의 Google 계정 백업 공간에 암호화하여 보관할 수 있습니다. 이는 Google의 기기 백업 기능이며 개발자는 이 데이터에 접근할 수 없습니다.

3. 제3자 제공

정보를 제3자에게 제공하거나 판매하지 않습니다. 광고, 분석, 추적 도구를 포함하지 않습니다.

4. 보관 기간과 삭제

  • 정보는 사용자가 삭제할 때까지 기기에 보관됩니다.
  • 앱의 설정 → 내 데이터 모두 삭제로 로그인한 계정의 모든 정보를 즉시 삭제할 수 있습니다.
  • 앱을 삭제하면 기기에 저장된 모든 정보가 함께 삭제됩니다.

5. 투자 정보에 관한 안내

앱이 보여주는 목표 달성률, 필요 금액, 예상 도달 시점, 목표 구성과의 차이 등은 사용자가 입력한 값으로 계산한 결과이며 투자 권유나 자문이 아닙니다.

6. 아동

자산관리는 만 14세 미만 아동을 대상으로 하지 않습니다.

7. 방침의 변경

이 방침이 바뀌면 이 페이지에 시행일과 함께 게시합니다.

8. 문의
