연동 키 발급 가이드

거래소·증권사 잔고를 자산관리에 자동으로 불러오려면, 각 회사 사이트에서 조회용 API 키를 직접 만들어 앱에 붙여 넣어야 해요. 기관을 골라 순서대로 따라 하세요.

업비트빗썸바이낸스 한국투자증권키움증권LS증권

시작하기 전에

  • 조회 권한만 켜 주세요. 주문·출금·이체 권한은 필요 없어요. 앱은 잔고를 읽기만 해요.
  • 키는 이 폰에만 암호화해서 저장돼요. 백업 파일이나 Google 드라이브에도 올라가지 않아요.
  • Secret Key(시크릿키)는 발급 화면에서 한 번만 보여 주는 곳이 많아요. 바로 복사해 앱에 붙여 넣으세요. 놓쳤다면 키를 지우고 새로 만들면 돼요.
  • 허용 IP를 꼭 넣어야 하는 곳(업비트·빗썸·키움)은 앱 연동 화면의 지금 이 폰의 IP 확인 버튼으로 IP를 복사해 넣으세요. 집 와이파이에 연결된 상태에서 확인해야 해요. 휴대폰 데이터 IP는 자주 바뀌어요.
가상자산 거래소

업비트 IP 등록 필수

upbit.com ↗
  1. 휴대폰이나 PC 브라우저로 upbit.com에 로그인해요. (업비트 앱에는 키 발급 메뉴가 없어요)
  2. 마이페이지 → Open API 관리로 들어가요.
  3. 권한은 자산조회만 체크해요.
  4. 특정 IP에서만 실행에 자산관리 앱에서 복사한 IP를 넣어요.
  5. 약관에 동의하고 Open API Key 발급받기 → 카카오페이·네이버 등으로 인증해요.
  6. 나온 Access Key와 Secret Key를 앱에 붙여 넣어요.
업비트 키는 발급 후 1년이 지나면 만료돼요. 만료되면 같은 방법으로 새 키를 만들어 앱의 연결 관리 → 다시 인증에 넣어 주세요.

빗썸 IP 등록 필수

bithumb.com ↗
  1. 브라우저로 bithumb.com에 로그인해요.
  2. 마이페이지 → API 관리로 들어가요.
  3. API 키 생성에서 권한은 자산조회만 켜요.
  4. 허용 IP에 자산관리 앱에서 복사한 IP를 넣어요.
  5. 보안 인증을 마치면 나오는 Access Key(Connect Key)와 Secret Key를 앱에 붙여 넣어요.

바이낸스

API 관리 ↗
  1. 바이낸스에 로그인하고 프로필 → API 관리로 들어가요.
  2. API 생성 → 시스템 생성을 고르고 이름(예: 자산관리)을 정해요.
  3. 보안 인증을 마치면 키가 만들어져요. 권한은 기본값인 읽기 허용(Enable Reading)만 둬요.
  4. API Key와 Secret Key를 앱의 Access Key·Secret Key 칸에 붙여 넣어요.
바이낸스는 IP 제한이 없어도 조회 키를 쓸 수 있어요. 더 안전하게 쓰고 싶다면 IP 제한을 켜고 집 와이파이 IP를 넣어도 돼요.

IP 등록이 번거롭다면

키 없이도 코인을 관리할 수 있어요. 자산 추가에서 거래소를 고르고 보유 수량만 넣으면, 시세는 앱이 받아와 금액을 자동으로 계산해요. 연동 화면의 키 없이 수량으로 입력하기를 눌러도 돼요.

증권사

한국투자증권

KIS Developers ↗
  1. 한국투자 앱이나 홈페이지에서 KIS Developers 서비스 신청을 해요. (홈페이지: 트레이딩 → Open API)
  2. 연동할 계좌를 고르고 약관에 동의해요. 계좌 하나에 키 하나가 나와요.
  3. apiportal.koreainvestment.com에 로그인하면 앱키(App Key)와 앱시크릿(App Secret)을 볼 수 있어요.
  4. 앱에 앱키·앱시크릿과 계좌번호 10자리(종합계좌 8자리 + 상품코드 2자리, 예: 12345678-01)를 넣어요.
모의투자 키가 아니라 실전투자 키를 넣어 주세요. 계좌가 여러 개면 계좌마다 따로 신청하고 따로 연결해요.

키움증권 IP 등록 필수

키움 REST API ↗
  1. openapi.kiwoom.com에 키움 아이디로 로그인해요.
  2. API 사용신청에서 연동할 계좌를 고르고 신청해요.
  3. 허용 IP에 자산관리 앱에서 복사한 IP를 등록해요.
  4. 앱키 관리에서 앱키(App Key)와 시크릿키(Secret Key)를 복사해 앱에 붙여 넣어요.
예전 방식인 ‘영웅문 OpenAPI(OCX)’가 아니라 REST API 키여야 해요.

LS증권

LS증권 OPEN API ↗
  1. openapi.ls-sec.co.kr에 LS증권 아이디로 로그인해요.
  2. API 신청에서 연동할 계좌를 고르고 신청해요.
  3. 발급된 앱키(App Key)와 시크릿키(Secret Key)를 복사해 앱에 붙여 넣어요.
각 회사 사이트의 메뉴 이름은 바뀔 수 있어요. 막히는 곳이 있으면 앱의 설정 → 의견 보내기로 알려 주세요.
